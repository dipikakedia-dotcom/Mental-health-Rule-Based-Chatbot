# Mental Health Support Chatbot
This is a simple Rule-Based Chatbot built using Python.

## About
This chatbot is built to answer queries based on predefined supportive responses and users choice of domain. 
It was built as a beginner project to understand the basic concept of chatbots and python.

## Main features
Responds to various domains
1. Health related concerns.
2. Self-doubt
3. Family and relationship issues.
4. Academic stress.
5. General low mood.
6. Interactive terminal-based conversation.
7. Predefined supportive responses.

## Technologies Used
- Python
    - Conditonal Statements.
    - Iterative Statements.
    - Jump Statements.
- Rule-based Chatbot logic.

## How to Run
Make sure that python is installed, then run:

bash
python MedBot.py
